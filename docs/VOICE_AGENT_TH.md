# ElevenLabs Voice Agent — Uncle Desktop 0.11.0

เลือกได้สองระบบในหน้า **สั่งงานด้วยเสียง → ระบบสนทนาด้วยเสียง**:

- **Uncle เดิม**: Local Thonburian/Whisper, Gemini หรือ OpenAI ถอดเสียง แล้วใช้ AI และเสียงตอบที่ตั้งไว้เดิม
- **ElevenLabs Voice Agent**: สนทนาเสียงต่อเนื่อง รับการพูดแทรก ใช้เสียงและสมองของ ElevenLabs Agent และเรียกเครื่องมือของ Uncle ผ่าน client tools

สลับระบบได้โดยไม่ลบค่าของอีกระบบ เปิดโปรแกรมใหม่ไมค์ยังปิดอยู่จนกดเริ่มเอง

## ตั้งค่าครั้งแรก

1. เลือก ElevenLabs แล้วใส่ API key คีย์เข้ารหัสด้วยบัญชี Windows ไม่ส่งคีย์ให้หน้า renderer และไม่บันทึกคีย์ใน log
2. เปิดสิทธิ์คีย์ **Voices Read** และ **ElevenAgents/Agents Read + Write** รวม Tools Read/Write หากหน้า ElevenLabs แยกสิทธิ์นี้ ชื่อสิทธิ์จาก API คือ voices_read, convai_read และ convai_write
3. ยินยอมส่งเสียง บทสนทนา และผลเครื่องมือไป ElevenLabs บริการใช้เครดิตในบัญชีของคุณ
4. กด **โหลดรายชื่อเสียง** เลือกเสียง หรือวาง Voice ID เลือกภาษาไทย/English
5. กด **สร้าง / อัปเดต Agent และเครื่องมือ** โปรแกรมสร้าง Agent ชื่อ Uncle Desktop ในบัญชีคุณและเก็บ Agent ID ไว้ การใส่ Agent ID เดิมแล้วกดอัปเดตจะเปลี่ยน prompt/เครื่องมือของ Agent นั้น
6. เลือกวิธีฟังและไมค์ กดบันทึก แล้วเริ่มฟัง หรือใช้ Ctrl+Alt+V

ภาษาไทยเลือก eleven_v3_conversational อัตโนมัติ ภาษาอังกฤษใช้ eleven_flash_v2_5 การทดสอบ API จริงพบว่า Flash v2.5 ปฏิเสธ Agent ภาษาไทย จึงใช้โมเดลที่รองรับ ตามรายการ [โมเดลของ ElevenLabs](https://elevenlabs.io/docs/overview/models/)

## กดเริ่ม หรือรอคำเรียก

**กดเริ่ม / จบสนทนาออนไลน์** เปิดไมค์ให้ ElevenLabs ระหว่างการสนทนา พูดแทรกขณะตอบได้ กดจบหรือ Ctrl+Alt+M เพื่อปิดทันที มีปุ่มพัก/เปิดไมค์ชั่วคราวระหว่างสนทนา

**รอคำเรียก** ตรวจชื่อในเครื่องด้วย Local model ที่เลือกไว้ จนพบคำเรียกที่ตั้งเองจึงเปิด ElevenLabs หากมีคำสั่งต่อจากชื่อจะส่งคำสั่งนั้นให้ Agent ด้วย ระหว่างสนทนาเสียงส่งออนไลน์ทั้งหมด เมื่อบริการจบการสนทนาปกติจะกลับไปรอชื่อในเครื่อง การกดหยุดเองไม่เปิดไมค์กลับอัตโนมัติ ความแม่นของคำเรียกยังขึ้นกับ Local model

กรณีเครือข่าย/บริการผิดพลาดจะหยุดและให้เริ่มใหม่ ไม่วนเปิดการสนทนาออนไลน์เอง

## เครื่องมือที่เชื่อม

มี client tools 13 หมวดตาม Hands ของ lachydotmcg: open_app, open_website, media, look_at_screen, play_music, app_window, use_computer, shortcut, remember, power, nap, move_yourself และ animate

คำสั่งเดี่ยวใช้เครื่องมือเดิมโดยตรง งานหลายขั้นตอนใช้ AI ในหน้า **ตั้งค่า AI** วางแผนควบคุมเครื่อง ดังนั้นสมองสนทนา ElevenLabs กับสมองทำงานหลายขั้นตอนแยกกัน

ต้องอนุญาต **อ่านหน้าต่าง** และ **เริ่มงานด้วยเสียง** ในหน้า **ควบคุมเครื่อง** ก่อน เครื่องมือไม่ข้ามสิทธิ์เดิม การดูภาพต้องอนุญาตภาพและใช้โมเดลรับภาพ งาน look_at_screen ถูกจำกัดให้อ่านอย่างเดียว

เมื่อระบบงานถามยืนยัน Agent จะอ่านคำถาม ตอบ “ใช่”/“ยกเลิก” หรือให้ข้อมูลเพิ่มเติมได้ คำตอบผูกกับรหัสงาน/คำถาม และรับเฉพาะ transcript ฝั่งผู้ใช้ เสียงตอบของ Agent ไม่ยืนยันตัวเอง ปุ่มยืนยันเดิมยังใช้ได้

“รับงานแล้ว” ยังไม่ใช่ “ทำสำเร็จ” ระบบส่งผลที่ตรวจแล้วกลับให้ Agent อธิบาย กด Ctrl+Alt+X หยุดงานควบคุมได้ ส่วนการสนทนายังเปิดจนกดปิดไมค์

ครอบคลุมหมวดเครื่องมือและวงจรเสียงหลัก แต่ไม่ใช่โปรแกรม C# ของต้นฉบับทั้งหมด: ใช้หน้าตั้งค่า/ตัวละครเดิมของ Uncle ไม่มีหน้าต่าง Capri Mainframe แยก ไม่ได้ย้าย security presets หรือพารามิเตอร์ย่อยทุกตัว เช่น นัดปิดเครื่องเป็นนาที/เลือกทิศทางจอจากเสียง

## คีย์และความเป็นส่วนตัว

กด **ลบคีย์ที่บันทึกไว้** เพื่อลบคีย์ในเครื่องและจบการเชื่อมต่อ การเพิกถอนคีย์จริงต้องทำในเว็บไซต์ ElevenLabs แยกต่างหาก การลบคีย์ไม่ลบ Agent และเครื่องมือในบัญชี

มีไมค์/สถานะออนไลน์แสดงระหว่างสนทนา ไม่เก็บประวัติหรือไฟล์เสียงสนทนาเพิ่มในโปรแกรม การเก็บข้อมูลฝั่ง ElevenLabs ขึ้นกับการตั้งค่าบัญชี/Agent ของคุณ ไม่รับประกัน zero retention

## ผลตรวจ 30 ตุลาคม 2026

- สร้างเครื่องมือ 13 หมวดและ Agent ไทยในบัญชีทดสอบจริงสำเร็จ
- SDK ทางการ 1.32.1 โหลด AudioWorklets จากไฟล์ในโปรแกรม ไม่มีการโหลดสคริปต์จาก CDN
- ทดสอบเสียงไทยสังเคราะห์ “ตอนนี้กำลังเล่นเพลงอะไร ช่วยตรวจเพลงที่กำลังเล่นให้หน่อย” บริการถอดตรงตามข้อความ เรียก media อ่านข้อมูลจริง และจบงานสำเร็จ
- ทดสอบพูดแทรกจริง บริการหยุดคำตอบเก่า รับประโยค “หยุดก่อนค่ะ ขอให้ตอบสั้นๆ ว่าได้ยินแล้ว” และตอบ “ได้ยินแล้วค่ะ”
- ไม่ส่งเสียงไมค์รอบตัวผู้ใช้ในการทดสอบบริการจริง ใช้ MediaStream จากไฟล์เสียงสังเคราะห์ ไม่ใช่ benchmark ความแม่นกับเสียงมนุษย์/สำเนียง/เสียงรบกวน
- ทดสอบระบบเดิมกับ Gemini และไฟล์เสียงไทยซ้ำผ่าน ไม่ลบ API key หรือค่าของระบบเดิม
