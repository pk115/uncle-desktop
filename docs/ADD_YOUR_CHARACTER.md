# เพิ่มตัวละครของคุณ

คลิกขวาที่ตัวละคร → **เลือกตัวละคร…** → **＋ เพิ่มตัวละครของฉัน**

1. เลือกภาพ PNG พื้นหลังโปร่งใส เห็นตัวละครเต็มตัวหรือครึ่งตัว
2. ตั้งชื่อ แอปเติมชื่อไฟล์ให้ก่อนแล้วแก้ได้
3. ใส่นิสัยตอนคุยถ้าต้องการ เช่น “ใจดี พูดไทย ชอบให้กำลังใจ”
4. ดูตัวอย่าง แล้วกด **เพิ่มและใช้ตัวละครนี้**

ภาพที่เพิ่มเองเป็นภาพนิ่ง ใช้ภาพเดียวทุกสถานะ มีประวัติแชตแยกตามตัวละคร แอปจัดขนาดและตำแหน่งภาพให้ ไม่ต้องเตรียม sprite sheet เอง

## ถ้ายังไม่มีภาพ

เปิด **ยังไม่มีภาพ? ดาวน์โหลดตัวอย่าง / สร้างด้วย AI** ในหน้าเดียวกัน

- **บันทึก PNG ตัวอย่าง**: เลือกที่บันทึกภาพ Blacky เต็มตัวโปร่งใส ลองนำกลับเข้าโปรแกรมได้ทันที ไฟล์ตัวอย่างอยู่ที่ `assets/characters/example.png`
- พิมพ์คำบรรยายหน้าตา แล้วกด **คัดลอกพรอมป์ต์** นำไปวางใน AI สร้างภาพที่คุณเลือก หากมีภาพอ้างอิงให้แนบด้วย จากนั้นบันทึกผลเป็น PNG แล้วกลับมาเลือกภาพ
- หน้านี้ไม่ได้เชื่อมบริการสร้างภาพอัตโนมัติ ไม่ต้องใส่ API key และไม่มีการคิดค่าบริการ AI จากปุ่มคัดลอกพรอมป์ต์

## ไฟล์และการลบ

รองรับ PNG ไม่เกิน 10 MB, ไม่เกิน 4096 พิกเซลต่อด้าน และไม่เกิน 12 ล้านพิกเซล ภาพที่ไม่มีพื้นหลังโปร่งใสยังใช้ได้ แต่จะแสดงคำเตือนว่าพื้นหลังติดมาด้วย แอปไม่ได้ลบพื้นหลังอัตโนมัติ

ตัวละครเก็บในโฟลเดอร์ `characters` ใต้พื้นที่ข้อมูลของแอป (`app.getPath('userData')`) แยกจากไฟล์ติดตั้ง จึงยังอยู่เมื่อเปิดแอปใหม่หรืออัปเดตตัวโปรแกรม แต่ละตัวมี ID เฉพาะ ภาพ และข้อมูลชื่อ/บุคลิก ไม่รับโค้ดหรือไฟล์รัน

เลือกการ์ดตัวที่เพิ่มเองแล้วกด **ลบตัวละครนี้** สองครั้งเพื่อยืนยัน ลบตัวติดโปรแกรมไม่ได้ หากลบตัวที่ใช้อยู่ แอปเปลี่ยนกลับ UncleDev ประวัติแชตเดิมยังเก็บไว้

## ตรวจสอบสำหรับผู้พัฒนา

- `npm test` — ข้อความ บุคลิก การเลือกตัวละคร และพรอมป์ต์
- `npm run test:characters:import` — ใช้ตัวอ่าน PNG จริงของ Electron ตรวจการนำเข้า ขนาด ความโปร่งใส เฟรมภาพนิ่ง การโหลดกลับ และการลบ
- `node scripts/smoke-character-import.js` — ทดสอบผ่าน UI และสร้างตัวทดสอบชั่วคราว จากนั้นเปิดแอปใหม่แล้วรัน `node scripts/smoke-character-import.js verify` เพื่อตรวจการจำตัวที่เลือกและลบตัวทดสอบออก
- `npm run test:characters:live` — ตรวจตัวละครติดโปรแกรมทั้งหมด
