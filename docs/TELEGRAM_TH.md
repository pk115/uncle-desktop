# คุยกับตัวละครผ่าน Telegram

สั่งงาน ถามข้อมูล และรับแจ้งเตือนจากมือถือ ส่งเป็นข้อความ ข้อความเสียง รูป หรือวิดีโอสั้นได้ ตัวละครตอบกลับเป็นข้อความหรือเสียง

## ตั้งค่า (ประมาณ 2 นาที)

1. **สร้าง bot**
   - ใน Telegram เปิดแชตกับ [@BotFather](https://t.me/BotFather) แล้วพิมพ์ `/newbot`
   - ตั้งชื่อ bot และชื่อผู้ใช้ที่ลงท้ายด้วย `bot` เช่น `my_uncle_bot`
   - BotFather จะส่ง **token** มาให้ หน้าตาแบบ `123456789:AA…`
2. **ใส่ token ในแอป**
   - บนคอม: คลิกขวาที่ตัวละคร › **ตั้งค่า…** › แท็บ **Telegram** › **ใส่ bot token…**
   - วาง token แล้วกด Enter ตัวละครจะบอกชื่อ bot ที่เชื่อมแล้ว
3. **ผูกกับแชตของคุณ**
   - กด **ผูกกับแชตของคุณ…** Telegram จะเปิดแชตกับ bot ของคุณ
   - กด **Start** ภายใน 10 นาที (หรือพิมพ์ `/start` ตามด้วยรหัส 6 หลักที่ตัวละครบอก)
   - bot จะตอบ "เชื่อมกับ Uncle Desktop แล้ว"

หลังผูกแล้ว bot จะคุยกับแชตของคุณเท่านั้น ใครที่ส่งข้อความมาหา bot ตัวละครจะไม่อ่านและไม่ตอบ

## ใช้งาน

| ส่ง | ตัวละครทำอะไร |
|---|---|
| 💬 ข้อความ | ตอบ และใช้เครื่องมือได้ เช่น ดูนัด สรุปเมล หรือเครื่องมือ MCP อื่น |
| 🎙 ข้อความเสียง | ถอดเสียงไทย (ตามที่ตั้งไว้ในหน้าไมค์) บอกว่าได้ยินว่าอะไร แล้วตอบ |
| 🖼 รูป | ดูรูปแล้วตอบตามคำบรรยายรูป เช่น "อ่านใบเสร็จนี้", "แปลป้ายนี้" |
| 🎬 วิดีโอสั้น | ดึงภาพ 6 เฟรมและถอดเสียงในคลิป แล้วสรุป (ไม่เกิน 20 MB) |

**คำสั่ง**
- `/new` เริ่มเรื่องใหม่
- `/help` ดูวิธีใช้

**งานที่ส่ง เขียน หรือลบข้อมูล:** เช่น ส่งเมลหรือสร้างนัด bot จะถามพร้อมปุ่ม **✓ อนุญาต / ✗ ไม่ต้อง** ถ้าไม่กดภายใน 5 นาทีถือว่าไม่ทำ

## 💻 Vibecode: สั่ง Claude Code / Codex จากมือถือ

โปรเจกต์อยู่ในโฟลเดอร์ Vibecode (ค่าเริ่มต้น `~/vibe-projects` เปลี่ยนได้ในแท็บ Telegram)

| คำสั่ง | ทำอะไร |
|---|---|
| `/create ชื่อ` หรือ `/create ชื่อ codex` | สร้างโปรเจกต์ใหม่ (git init) ใช้ Claude Code หรือ Codex แล้วเข้าโหมดเขียนโค้ด |
| `/projects` · `/project ชื่อ` | ดูรายชื่อ หรือเลือกโปรเจกต์ |
| `/code` · `/chat` | เข้าโหมดเขียนโค้ด (ทุกข้อความ เสียง และรูป ส่งให้ Agent) / กลับมาคุยปกติ |
| `/diff` | สรุปไฟล์ที่แก้ + ไฟล์ diff แนบมา |
| `/commit ข้อความ` | commit ทุกอย่าง |
| `/pr PIN` | สร้าง branch, push และเปิด pull request (ต้องมี remote และ `gh` login แล้ว) |
| `/undo PIN` | ย้อน commit ล่าสุด (`git revert`) |
| `/shot http://localhost:3000` | ภาพหน้าเว็บที่รันอยู่ในคอม |
| `/stop` | หยุด Agent |

- ระหว่างทำงาน ตัวละครส่งความคืบหน้าเป็นระยะ เช่น "🔧 Edit: src/app.js"
- เสร็จแล้วส่งคำตอบสุดท้ายพร้อมปุ่ม **ดูสิ่งที่แก้** / **commit**
- ส่งรูป mockup ในโหมดเขียนโค้ด Agent จะดูรูปแล้วทำตาม
- **ขออนุญาตจากมือถือ:** ทุกครั้งที่ Claude Code ขอสิทธิ์รันคำสั่งหรือแก้ไฟล์ ปุ่ม ✓ / ✗ จะเด้งมาใน Telegram (ไม่ตอบใน 10 นาทีถือว่าไม่อนุญาต)
- Codex ทำงานใน sandbox ที่เขียนได้เฉพาะในโฟลเดอร์โปรเจกต์
- **แจ้งเตือนจาก Claude Code บนคอม:** รออนุมัติหรือทำงานเสร็จ ส่งเข้ามือถือด้วย

## 🖥 สั่งคอมจากมือถือ (ปิดไว้เป็นค่าเริ่มต้น)

เปิดสวิตช์ในแท็บ Telegram และตั้ง **PIN** ก่อน ทุกคำสั่งต้องใส่ PIN:

| คำสั่ง | ทำอะไร |
|---|---|
| `/screen PIN` | ส่งภาพหน้าจอคอมมาให้ (ตัวละครบอกบนคอมทุกครั้ง) |
| `/pc PIN งาน` | สั่งงานควบคุมเครื่อง เช่น `/pc 1234 เปิด Spotify เล่นเพลงชิล` ใช้ระดับความปลอดภัยเดียวกับบนคอม เสร็จแล้วแจ้งกลับ |
| `/lock PIN` · `/sleep PIN` · `/shutdown PIN` · `/restart PIN` | ล็อก พัก ปิด หรือรีสตาร์ทเครื่อง |

## ตั้งค่าในแท็บ Telegram

- **ส่งแจ้งเตือนเข้ามือถือ:**
  - ทุกครั้ง
  - เฉพาะตอนไม่อยู่หน้าคอม (ไม่แตะเมาส์หรือคีย์บอร์ด 5 นาที)
  - ไม่ส่ง

  แจ้งเตือนที่ส่ง: เมลสำคัญ, นัดใกล้ถึง, ข่าว และสถานะงาน
- **ตอบกลับเป็นเสียง:** เมื่อคุณส่งเสียงมา / ทุกครั้ง / ไม่ตอบเป็นเสียง ใช้บริการเสียงที่เลือกในหน้าเสียงพูด
- **คุยและถามข้อมูลจากมือถือ:** ปิดได้ถ้าต้องการแค่แจ้งเตือน
- **อนุมัติงานจากมือถือ:** ถ้าปิด งานที่ต้องอนุมัติจะไม่ทำเมื่อสั่งจากมือถือ

## ข้อควรรู้

- **คอมต้องเปิดและแอปต้องรันอยู่:** ตัวละครดึงข้อความจาก Telegram เอง ไม่มีเซิร์ฟเวอร์กลาง
- **ข้อมูลผ่าน Telegram:** ข้อความ รูป และเสียงผ่านเซิร์ฟเวอร์ของ Telegram แล้วส่งให้ AI ที่คุณเลือกบนคอม ถ้าใช้ Ollama และ Whisper ในเครื่อง ส่วน AI ก็อยู่ในเครื่องทั้งหมด
- **ไม่เก็บไฟล์:** รูปและเสียงที่ส่งมา ไม่บันทึกลงคอม ประมวลผลแล้วทิ้ง
- **token:** เก็บแบบเข้ารหัสในเครื่อง ถ้า token หลุด ให้พิมพ์ `/revoke` กับ @BotFather แล้วใส่ token ใหม่
