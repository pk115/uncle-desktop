# การรองรับภาษาไทย

แอปใช้ภาษาไทยเป็นค่าเริ่มต้นสำหรับการตั้งค่าใหม่ เปลี่ยนได้โดยคลิกขวาที่ตัวละครหรือไอคอนถาดระบบ แล้วเลือก **ภาษา → ภาษาไทย** การเปลี่ยนภาษาจะโหลดหน้าตัวละครใหม่เพื่อเปลี่ยนข้อความในหน้าที่เปิดอยู่ด้วย

## ส่วนที่รองรับ

- เมนูถาดระบบ เมนูคลิกขวา หน้าต้อนรับ คู่มือ และการเชื่อม Coding Agent
- ตั้งค่า AI คีย์ API ที่อยู่เซิร์ฟเวอร์ บุคลิก ชื่อ และความทรงจำ
- แชต สถานะงาน สรุปภารกิจ การแจ้งเตือน ความผูกพัน และข้อความตอบสนองต่อเครื่อง
- คำแนะนำก่อนส่งภาพหน้าจอให้ AI ทั้งในเครื่องและออนไลน์
- ฟอนต์ไทยที่ติดตั้งมากับแอป ใช้งานได้โดยไม่ดาวน์โหลดฟอนต์เพิ่ม
- แสดงสระและวรรณยุกต์เป็นกลุ่มเดียวกันระหว่างเอฟเฟกต์ข้อความ

## ตัวอย่างคำสั่ง

ตัวอย่างด้านล่างใช้พิมพ์ในแชต รุ่น 0.6.0 รับเสียงจากไมค์และตั้งคำเรียกได้แล้ว ดู [คู่มือสั่งงานด้วยเสียง](VOICE_COMMANDS_TH.md) ดู [คู่มือเสียง](SPEECH_TH.md) และ [แผนฟีเจอร์ปัจจุบัน](FEATURE_ROADMAP_TH.md)

- `เรียกฉันว่าปุ๊กกี้`
- `จำไว้ว่าฉันชอบแมว`
- `เตือนฉันให้พักสายตาอีก 10 นาที`
- `ช่วยเตือนดื่มน้ำใน ๑๕ นาทีด้วย`
- `เตือนประชุมพรุ่งนี้เวลา ๐๙:๓๐`
- `ดูหน้าจอของฉัน`
- `แคปหน้าจอ`
- `เพิ่มเสียง`, `ลดเสียง`, `หยุดเพลง`, `เพลงถัดไป`
- `เปิดเพลง ลม บน YouTube`
- `ค้นหาแมวใน Google`

เวลาระบุแบบ `เวลา 09:30` ใช้ระบบ 24 ชั่วโมง รองรับระยะเวลาเป็นตัวเลขอารบิกและเลขไทย รวมถึง `อีกครึ่งชั่วโมง` ยังไม่รองรับสำนวนเวลาทุกแบบ เช่น `บ่ายสาม` หรือ `ห้าโมงเย็น`

## การตรวจสอบ

รัน `npm test` เพื่อตรวจชุดทดสอบเดิมและชุดภาษาไทย ซึ่งตรวจคีย์คำแปลและตัวแปรให้ตรงภาษาอังกฤษ ตรวจชื่อไทย เลขไทย เวลาแจ้งเตือน คำสั่งแชต และการแบ่งกลุ่มตัวอักษร

ตรวจแอปจริงแล้ว: เมนูและหน้าต้อนรับภาษาไทย หน้าตั้งค่า AI ฟอนต์ไทย และการเปลี่ยน English → ภาษาไทย ไม่พบข้อความล้นในหน้าต้อนรับและหน้าตั้งค่า AI ที่ตรวจ

ชื่อผลิตภัณฑ์ โมเดล ไฟล์ โค้ด และรายละเอียดข้อผิดพลาดจากระบบหรือบริการภายนอกยังคงต้นฉบับเพื่อใช้แก้ปัญหา คำสั่งให้โมเดลตอบภาษาไทยเพิ่มแล้ว แต่คุณภาพคำตอบขึ้นอยู่กับโมเดลที่เลือก ยังไม่ได้ทดสอบเสียงพูดภาษาไทยหรือบทสนทนาจริงกับทุกโมเดล
