# ควบคุมเครื่อง — Uncle Desktop 0.9.0

## ใช้งาน

คลิกขวาที่ตัวละคร → ควบคุมเครื่อง / งานหลายขั้นตอน หรือ ตั้งค่าทั้งหมด → ควบคุมเครื่อง
ระบุงาน เช่น “เปิด Notepad แล้วพิมพ์ สวัสดีจาก Uncle” เลือกอนุญาตอ่านหน้าต่าง/ใช้เมาส์คีย์บอร์ด แล้วกดเริ่ม
แชตหรือเสียงขึ้นต้น “ควบคุมเครื่อง …” / “ทำงานบนเครื่อง …” จะเปิดแผงพร้อมงานให้ตรวจและเริ่ม

- AI ใช้ provider/model จากตั้งค่า AI ตอนเริ่มงาน แล้วคงตัวนั้นตลอดงาน รองรับ Gemini, OpenAI-compatible และ Ollama
- หากเลือกใช้ภาพ ต้องใช้โมเดลที่รับภาพได้; ค่าเริ่มต้นอ่านปุ่ม/ช่องกรอกผ่าน Windows UI Automation โดยไม่ส่งภาพ
- คีย์หยุดเริ่มต้น Ctrl+Alt+X เปลี่ยนได้ในตั้งค่าทั้งหมด; มีปุ่มหยุดด้านบนจอและเมนูถาด
- หยุดแล้วผล AI หรือการอนุมัติที่มาช้าจะไม่ทำงานต่อ

## ทำอะไรได้

อ่านหน้าต่าง/ปุ่ม/ช่องกรอก สลับหน้าต่าง เปิดแอป/เว็บ คลิก ดับเบิลคลิก คลิกขวา พิมพ์ Unicode ภาษาไทย กดคีย์ลัด และเลื่อน
AI ทำหนึ่งขั้นแล้วอ่านผลใหม่ มีรายการขั้นตอนและข้อความสถานะ ไม่ถือว่าคำตอบ “ทำแล้ว” ของ AI เป็นผลเครื่องมือ
จบด้วย done ต้องยกข้อความหลักฐานที่อยู่ในหน้าต่างล่าสุด มิฉะนั้นระบบหยุดพร้อมข้อผิดพลาด
แอปที่ไม่มี accessibility ใช้ภาพพื้นที่หน้าต่างขนาดไม่เกิน 1280px และพิกัดที่ตรวจขอบเขต; คลิกตามพิกัดต้องยืนยัน

## ขอบเขต

รองรับ Windows 10/11 x64 ในรุ่นนี้ ไม่เพิ่มสิทธิ์ administrator
จำกัด 30 ขั้น/10 นาที หยุดเมื่อคำสั่งผิดรูปแบบ เป้าหมายหรือหน้าต่างเปลี่ยน ทำขั้นตอนเดิมซ้ำ หรือเครื่องมือค้าง
ช่องรหัสผ่านและช่องข้อมูลบัตร/OTP ที่อ่านระบุได้จะไม่ส่งค่าให้ AI และไม่กรอก/วางให้ พบช่องลับใน observation จะงดภาพทั้งหน้าต่าง
การส่ง/โพสต์/ลบ/ติดตั้ง/บันทึก/ชำระที่ตรวจพบจากปุ่ม รวมถึง Enter, paste และคีย์ที่อาจเปลี่ยนข้อมูล จะถามยืนยันขั้นตอนนั้น (60 วินาที)
การตรวจชื่อปุ่มเป็นกฎ ไม่ใช่การจำแนกผลกระทบครบทุกภาษาและทุกแอป; ต้องตรวจรายละเอียดก่อนยืนยัน
ไม่รัน shell/script, ไม่พิมพ์ใน terminal/Run/Console และไม่เปิดไฟล์รันเองจากผลค้นหาแอป
ภาพและขั้นตอนอยู่ในหน่วยความจำ ไม่เพิ่มไฟล์ screenshot/history งานลงดิสก์; ข้อมูลหน้าต่างถูกส่งไปยัง provider ที่ผู้ใช้เลือกตามคำยินยอม

ยังไม่มีลากเมาส์ งานข้ามเครื่อง macOS การยืนยันงานด้วยเสียงทั้งเส้นทาง หรือรับประกันทุกเว็บ/ทุกแอป
แอป custom canvas และเกมอาจอ่านข้อความ/ปุ่มไม่ได้ แม้คลิกผ่านภาพได้ก็อาจไม่มีข้อความหลักฐานให้ตรวจจบงาน

## การทดสอบ

- npm test: กฎคำสั่ง ข้อมูลเกินขอบเขต การยืนยัน หน้าต่างเปลี่ยน late result และการตรวจหลักฐาน
- npm run test:computer:live: สร้างหน้าต่าง QA ชั่วคราว อ่าน UIA พิมพ์ไทย คลิก ตรวจป้าย ปกปิด/ปฏิเสธช่องรหัสผ่าน และตรวจขอบเขตภาพ ปิดและลบทิ้งหลังเทสต์
- scripts/live-computer-test.js: ทดสอบ Gemini จริงกับหน้าต่าง QA ที่จำกัดเป้าหมาย ไม่แก้โปรไฟล์หรือแอปผู้ใช้
- node scripts/smoke-computer-app.js: เมื่อเปิด --dev ทดสอบ renderer → IPC → provider จริง → native → ตรวจผล

### เริ่มใช้เสียงกับงานควบคุม

1. ตั้งค่า AI, เสียงพูด และไมโครโฟนตามปกติ เลือกกดพูดหรือรอคำเรียกที่ตั้งเอง
2. เปิด **ควบคุมเครื่อง** อนุญาตอ่านหน้าต่าง และเลือก **ให้คำสั่งเสียงเริ่มงานได้อัตโนมัติ** บันทึกเมื่อเริ่มงาน หรือให้ระบบถามอนุญาตครั้งแรกจากเสียง
3. พูด เช่น “เปิด Notepad แล้วพิมพ์ สวัสดีจาก Uncle” เมื่อถามขั้นตอนสำคัญ พูด “ใช่” หรือ “ยกเลิก” ไม่ต้องเรียกชื่อซ้ำ
4. ระหว่างงานพูด “หยุดงาน” หรือกด **Ctrl+Alt+X** ได้ การพูดทับเสียงตอบยังพักไมค์เพื่อกันระบบฟังตัวเอง ใช้ปุ่มหยุดได้ทันที

จำการอนุญาตตาม AI provider ที่เลือก ยกเลิกโดยเอาเครื่องหมายอนุญาตออกแล้วกดบันทึกสิทธิ์ การเปลี่ยน provider ต้องอนุญาตอ่านหน้าต่างใหม่
คำยืนยันผูกกับรหัสงานและคำถาม ไม่ใช้คำตอบเก่ากับคำถามใหม่ หน้าต่างยืนยันจะปิดก่อนคืนเมาส์ให้แอปเป้าหมาย
