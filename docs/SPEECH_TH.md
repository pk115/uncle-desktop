# เสียงพูดใน Uncle Desktop 0.7.0

คลิกขวาที่ตัวละครหรือไอคอนถาดระบบ → **เสียงพูดภาษาไทย…**

## Edge Thai — พร้อมใช้ผ่านอินเทอร์เน็ต ไม่ต้องใส่คีย์

มีเสียงหญิง Premwadee และเสียงชาย Niwat ในรายการทันที เลือกเสียงและยินยอมส่งข้อความไป Microsoft Edge TTS แล้วทดสอบได้ ไม่ต้องติดตั้งภาษาไทยใน Windows และไม่ใช้เครดิต OpenAI แต่ต้องมีอินเทอร์เน็ต บริการอาจเปลี่ยนหรือไม่พร้อมใช้งานได้ จึงไม่มีการรับประกันความพร้อมแบบบริการ API แบบชำระเงิน

นำแนวทางจากโปรเจกต์ TTSLive/VoxLive ของผู้ใช้มาปรับ ใช้ `node-edge-tts` 1.2.12 ซึ่งรองรับการเชื่อมต่อ v2 ปัจจุบันแทนไลบรารี Universal รุ่นเดิมที่ได้รับ 403 ในการทดสอบ ใช้ worker ที่ยกเลิกได้เพื่อไม่ทิ้ง WebSocket ค้าง และส่ง MP3 ให้ renderer เล่นจากหน่วยความจำ

Edge เป็นบริการออนไลน์ ไม่ใช่การติดตั้งเสียงไทยออฟไลน์ ถ้าต้องการออฟไลน์ให้เลือก Windows และติดตั้งเสียงไทยในระบบก่อน แอปจะไม่สลับไปส่งข้อความให้ provider อื่นเองโดยไม่เลือก

## Windows — อ่านในเครื่อง

เลือกเสียงที่ติดตั้งอยู่ใน Windows จากนั้นแก้ข้อความทดสอบและกด **ทดสอบเสียง** การอ่านแบบนี้ไม่ส่งข้อความออกจากเครื่องและไม่ต้องใช้คีย์ API

ถ้ารายชื่อไม่มีภาษาไทย กด **เปิดการตั้งค่าเสียง Windows** เพิ่มเสียงภาษาไทย แล้วกลับมากด **รีเฟรชรายชื่อเสียง** แอปจะไม่ใช้เสียงภาษาอังกฤษอ่านไทยแบบผิด ๆ แต่จะแจ้งให้เลือกเสียงที่รองรับแทน เครื่องทดสอบนี้มีเสียงอังกฤษสามตัวและยังไม่มีเสียงไทย จึงทดสอบเสียงจริงด้วยข้อความอังกฤษเท่านั้น

## OpenAI — เสียง AI ออนไลน์

เลือก OpenAI แล้วเลือกเสียง เช่น coral ใส่ OpenAI API key หากยังไม่มีคีย์บันทึกอยู่ และยินยอมส่งข้อความไปบริการ คีย์ที่ใส่ในหน้านี้เก็บผ่าน Windows encryption และไม่ส่งกลับไปแสดงในหน้า UI คีย์ OpenAI ใช้ร่วมกับการตั้งค่าแชต

เสียงสร้างโดย AI และมีค่าบริการ API ตามบัญชีของคุณ การสมัครแชตไม่ได้หมายความว่ามีเครดิต API แอปไม่ส่งภาพหน้าจอหรือเสียงไมค์ไปกับการอ่านนี้ และไม่มีการเรียกบริการออนไลน์จนกว่าจะสั่งอ่านหรือเปิดอ่านอัตโนมัติไว้

อ้างอิง: [OpenAI Text to Speech](https://developers.openai.com/api/docs/guides/text-to-speech) รุ่นนี้ใช้ `gpt-4o-mini-tts` และเสียง WAV

## การใช้งาน

- **ทดสอบเสียง** — อ่านข้อความตัวอย่างที่แก้ไขได้ พร้อมบันทึกตัวเลือกเสียง
- **อ่านข้อความตอบล่าสุด** — อ่านคำตอบแชตล่าสุด
- **อ่านคำตอบแชตอัตโนมัติ** — ปิดเป็นค่าเริ่มต้น เปิดเองได้
- **หยุดเสียง** — ยกเลิกทั้งการสร้างเสียงที่รออยู่และเสียงที่เล่นแล้ว มีปุ่มหยุดลอยอยู่ด้วยเมื่อกำลังอ่าน
- ปรับระดับเสียงและความเร็วได้ การปิดเสียงแอปและเปลี่ยนตัวละครจะหยุดเสียงด้วย

อ่านสูงสุด 2,000 ตัวอักษรต่อครั้ง ข้าม code blocks และ URL เพื่อให้อ่านข้อความได้เข้าใจง่ายขึ้น มี [โหมดไมโครโฟนและถามยืนยัน](VOICE_COMMANDS_TH.md) แล้ว แต่ยังไม่มี lip sync

## การตรวจสอบ

`npm test` ครอบคลุมการตั้งค่า การยินยอม คีย์ที่ขาด การยกเลิก ข้อผิดพลาดบริการ และการเตรียมข้อความ โดยใช้บริการจำลองสำหรับ OpenAI จึงไม่มีค่า API จากการทดสอบ

`node scripts/smoke-speech.js` ใช้กับแอป `--dev` บน Windows เพื่อทดสอบเสียง Windows จริง การเล่น/หยุด และหน้าตั้งค่าออนไลน์ เครื่องทดสอบต้องมีเสียงอังกฤษติดตั้งอย่างน้อยหนึ่งตัว

ยังไม่ได้ทดสอบคุณภาพเสียงไทยจาก OpenAI แบบเรียกบริการจริง เนื่องจากไม่มีคีย์สำหรับการทดสอบ และยังไม่ได้ประเมินเสียงไทย Windows บนเครื่องที่ติดตั้งเสียงไทยแล้ว

อัปเดต QA 0.7.0: ทดสอบสร้างเสียงไทย Edge ชายและหญิงจริง พร้อม decode/playback ใน Electron; ทดสอบเปิด Notepad จริง → ถามยืนยันด้วยเสียงไทย → “ไม่ใช่” ไม่ปิด → “ใช่” จึงปิด โดยจำลองเฉพาะ STT transcript เพื่อทดสอบเส้นทางคำสั่งซ้ำได้ ไม่มีการเรียก LLM/OpenAI ใน smoke นี้
