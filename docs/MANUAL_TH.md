## 1. เริ่มต้นใช้งาน

1. **ดาวน์โหลด:** ไฟล์ติดตั้งอยู่ที่ [หน้า Releases](https://github.com/pk115/uncle-desktop/releases/latest)
   - Windows: `Uncle-Desktop-Setup-x.y.z.exe`
   - Mac: `.dmg` ดู[วิธีติดตั้งบน Mac](INSTALL_MAC_TH.md)
2. **ตั้งค่าครั้งแรก:** เปิดครั้งแรกจะมีหน้าตั้งค่าทีละขั้น 6 ขั้น
   - ตัวละคร
   - AI ที่ใช้คุย
   - เสียงพูด
   - ไมค์
   - Coding AI
   - เสร็จ
3. **อัปเดต:**
   - ตัวละครจะบอกเมื่อมีเวอร์ชันใหม่
   - Windows ติดตั้งให้เองเมื่อรีสตาร์ทแอป
   - Mac พาไปหน้าดาวน์โหลด

> ทุกอย่างที่ส่งข้อมูลออกนอกเครื่อง (AI ออนไลน์ เสียงออนไลน์ ถอดเสียงออนไลน์) จะถามความยินยอมก่อนเสมอ

## 2. เมนูคลิกขวาและหน้าตั้งค่า

### เมนูคลิกขวา
คลิกขวาที่ตัวละคร หรือที่ไอคอนในถาดระบบ (Mac คือ menu bar) จะเจอสิ่งที่ใช้ประจำ:

| เมนู | ทำอะไร |
|---|---|
| คุยกับตัวละคร | เปิดช่องแชต |
| เริ่มพูด / ปิดไมค์ | เริ่มฟังตามโหมดที่ตั้งไว้ หรือปิดไมค์ |
| **โหมดไมค์** | เลือก กดพูด / เรียกชื่อแล้วสั่ง / ฟังตลอด แล้วเริ่มฟังทันที |
| ดูหน้าจอของฉัน | ให้ AI ดูหน้าจอแล้วพูดถึงสิ่งที่เห็น |
| ขนาด, มุมมอง, โมเดล AI | ปรับด่วนโดยไม่ต้องเข้าหน้าตั้งค่า |
| ปิดเสียง, ซ่อน | |
| ตั้งค่า… | หน้าตั้งค่าแบบแท็บ |

### หน้าตั้งค่า (8 แท็บ)

| แท็บ | มีอะไร |
|---|---|
| **ตัวละคร** | เลือกตัว (มีรูปตัวอย่าง), ขนาด, เต็มตัว/ครึ่งตัว, นำเข้าตัวละครเอง |
| **AI แชต** | ผู้ให้บริการ AI, โมเดล, คีย์, ระดับความฉลาด, โมเดลแยกตามงาน |
| **เสียงและไมค์** | เสียงพูด, ไมค์และคำเรียก, รูปแบบสถานะไมค์และมินิเพลเยอร์, คืนตำแหน่งไอคอน |
| **พฤติกรรม** | เดินเล่น, เข้าสิงหน้าต่าง, หึง, มินิเพลเยอร์และเต้น, ที่พัก, การเคลื่อนไหว |
| **ผู้ช่วย** | Gmail, Google Calendar, MCP, VIP, งาน |
| **ข่าวและสรุป** | หัวข้อข่าว, คำเตือนข่าวด่วน, เวลาสรุปเช้าและเย็น |
| **Telegram** | bot token, ผูกแชต, PIN, การแจ้งเตือนเข้ามือถือ, Vibecode, LINE |
| **ระบบ** | คีย์ลัด, ภาษา, เปิดพร้อมเครื่อง, ล้างการตั้งค่าทั้งหมด |

## 3. ตัวละคร

- **เปลี่ยนตัว:**
  - ตั้งค่า › ตัวละคร (มีรูปตัวอย่าง)
  - หรือ **ชี้เมาส์ที่ตัวละคร กด Ctrl ค้างแล้วหมุนลูกกลิ้ง:** ลง = ตัวถัดไป, ขึ้น = ตัวก่อนหน้า วนกลับเมื่อสุดรายการ
- **ขนาดและมุมมอง:** คลิกขวา › ขนาด / มุมมอง (เต็มตัว หรือครึ่งตัว)
- **ลาก ขว้าง วาง:** ลากตัวละครไปไหนก็ได้ ขว้างแล้วตกตามแรงโน้มถ่วง นั่งบนขอบหน้าต่างได้
- **เก็บเข้าไบโอชิป:** Ctrl+Alt+C เก็บเป็นชิปเล็กที่มุมจอ กดอีกครั้งหรือคลิกชิปเพื่อเรียกออกมา
- **ที่พัก:** มุมจอ หรือนั่งบน taskbar (ตั้งค่า › พฤติกรรม)
- **นำเข้าตัวละครเอง:** ดู [ADD_YOUR_CHARACTER.md](ADD_YOUR_CHARACTER.md) และ [CHARACTERS.md](CHARACTERS.md)

## 4. คุยกับตัวละครและสมอง AI

- **เปิดแชต:** คลิกตัวละครแล้วกดปุ่มคุย หรือคลิกขวา › คุยกับตัวละคร
- **ผู้ให้บริการ:** Ollama (ในเครื่อง), OpenAI, Gemini, Mistral, DeepSeek, Pollinations, หรือเซิร์ฟเวอร์ที่ใช้รูปแบบ OpenAI
- **ระดับความฉลาด 3 ระดับ:** เร็ว / สมดุล / ฉลาดสุด เลือกโมเดลให้อัตโนมัติ
- **โมเดลแยกตามงาน:** ใช้เครื่องมือ / ควบคุมเครื่อง / งานเบื้องหลัง / ดูภาพ ใช้โมเดลต่างกันได้
- **บุคลิกและความจำ:**
  - `personality.md` กำหนดนิสัยตัวละคร
  - `me.md` เรื่องของคุณที่ตัวละครจำ
  - พูดว่า "จำไว้ว่า…" ในแชตเพื่อเพิ่มความจำ
- **คำสั่งด่วนในแชต:** เช่น เตือนความจำ เปิดแอป เปิดเว็บ ดูรายการใน README หัวข้อ "คำสั่งด่วนในแชต"

## 5. เสียงพูด

ตั้งค่าที่ ตั้งค่า › เสียงและไมค์ › **เสียงพูดภาษาไทย…**

| บริการ | ทำงานที่ไหน | ภาษาไทย | ต้องมี |
|---|---|:-:|---|
| เสียงของเครื่อง | ในเครื่อง | ✓ ถ้าติดตั้งเสียงไทย | — |
| Edge | ออนไลน์ | ✓ เปรมวดี, นิวัฒน์ | — (ฟรี) |
| **Kokoro** | **ในเครื่อง ฟรี** | **ทดลอง** | โหลดโมเดล ~90 MB ครั้งแรก |
| OpenAI | ออนไลน์ | ✓ | API key |
| ElevenLabs | ออนไลน์ | ✓ | API key + Voice ID |
| Fish Audio | ออนไลน์ | ✓ | API key (+ เสียงที่โคลนไว้) |
| เซิร์ฟเวอร์ของคุณ | ตามที่ตั้ง | ตามโมเดล | URL แบบ OpenAI `/v1/audio/speech` |

### Kokoro อ่านภาษาไทย (ทดลอง)
- **ใช้งาน:** เลือก Kokoro แล้วพิมพ์หรือคุยภาษาไทยได้เลย
- **ฟังเป็นไทยที่สุด:** เลือกเสียงจีน **Xiaoxiao** หรือ **Xiaobei** เพราะได้วรรณยุกต์ไทยด้วย เสียงอื่นอ่านได้แต่ไม่มีวรรณยุกต์
- **ทำงานยังไง:** แปลงข้อความไทยเป็นเสียงอ่านในเครื่องตามกฎภาษาไทย:
  - ตัดคำ อักษรนำ คำควบกล้ำ ตัวสะกด
  - ตัวเลข เวลา เลขไทย ๆ และตัวย่อ
  - คำอ่านไม่ตรงตัวราว 130 คำ
- **ข้อจำกัด:**
  - ยังมีสำเนียงต่างชาติ เพราะ Kokoro ไม่ได้ฝึกกับเสียงไทย
  - บางคำอาจอ่านผิด ถ้าเจอ แจ้งคำนั้นมาเพื่อเพิ่มในรายการแก้
- **ข้อความไทยปนอังกฤษ:** ส่วนอังกฤษอ่านด้วยตัวอ่านอังกฤษ ใช้ได้ทุกเสียง

### ปรับเสียง
- **เปิดที่:** ▶ ปรับเสียง
- **ระดับเสียง (pitch):** ±12 ครึ่งเสียง
- **Robot:** เสียงหุ่นยนต์
- **Glitch:** เสียงขาดเป็นช่วง
- **ซ้อนเสียง:** เพิ่มเสียงตัวเองอีกสองชั้น สูงหนึ่ง ต่ำหนึ่ง
- **อ่านคำตอบแชตอัตโนมัติ:** ติ๊กในหน้าเดียวกัน

## 6. สั่งงานด้วยเสียง (ไมค์)

### ตั้งค่าครั้งแรก
1. ตั้งค่า › เสียงและไมค์ › **ไมค์ คำเรียก และ ElevenLabs…**
2. **เลือกตัวถอดเสียง:**
   - **Local:** ในเครื่อง ฟรี ต้องกด "ดาวน์โหลดโมเดล" ครั้งแรก รุ่น small หรือ Thonburian ที่เก่งภาษาไทย
   - **Gemini หรือ OpenAI:** ออนไลน์ ต้องใช้คีย์และกดยินยอม
3. **เลือกไมค์และความไว** แล้วกด **ทดสอบเสียง / คำเรียก** (ทดสอบอย่างเดียว ไม่ส่งคำสั่ง)

### วิธีฟัง 3 แบบ

| โหมด | ใช้ยังไง | เหมาะกับ |
|---|---|---|
| **กดพูด** | กด Ctrl+Alt+V พูดจบแล้วระบบถอดเสียงเอง | ใช้นานๆ ครั้ง เป็นส่วนตัวที่สุด |
| **เรียกชื่อแล้วสั่ง** | พูดคำเรียก เช่น "เฮ้ อังเคิล เปิดเพลง" หลังเรียกแล้วพูดต่อได้อีกไม่กี่วินาทีโดยไม่ต้องเรียกซ้ำ | เปิดค้างไว้ ทำงานไปสั่งไป |
| **ฟังตลอด** | พูดคำสั่งได้เลยโดยไม่ต้องเรียกชื่อ | อยู่คนเดียว ห้องเงียบ |

- **เปลี่ยนโหมดด่วน:** คลิกขวา › **โหมดไมค์** เลือกแล้วเริ่มฟังทันที
- **คำเรียก:** ตั้งได้หลายคำ ควรเป็นคำหลายพยางค์ที่ไม่ได้พูดบ่อย
- **โหมดฟังตลอด:**
  - ทิ้งเสียงรบกวน คำสั้นๆ (อืม, เอ่อ, โอเค) และประโยคที่ระบบถอดเสียงมโนจากเสียงรบกวน (เช่น "ขอบคุณที่รับชม")
  - ถ้าใช้ตัวถอดเสียงออนไลน์ ทุกประโยคที่ไมค์ได้ยินจะถูกส่งไปถอดและเสียเงิน **แนะนำ Local**
  - ถ้ามีเสียงทีวีหรือคนคุยกัน ให้ลดความไวไมค์ หรือติ๊ก "ตรวจข้อความก่อนส่ง"
- **ไม่ฟังตัวเอง:** ระหว่างตัวละครพูดหรือคิดคำตอบ ไมค์ไม่รับเสียง
- **ยืนยันด้วยเสียง:** คำสั่งเสี่ยง (ปิดแอป ปิดเครื่อง ส่งเมล) ถามก่อนเสมอ ตอบ "ใช่" หรือ "ไม่" ด้วยเสียงได้
- **ไมค์ปิดทุกครั้งที่เปิดแอป:** จนกว่าคุณจะเปิดเอง

### สถานะไมค์
ตั้งค่า › เสียงและไมค์ › **สถานะไมค์**:
- **แบบเต็ม:** แถบข้อความ "■ ปิดไมค์ · …" มุมซ้ายล่าง
- **ไอคอนเล็ก:** วงกลมเล็กมุมขวาล่าง บอกขั้นตอนด้วยรูปและสี

| ไอคอน | ขั้นตอน |
|---|---|
| 🎙 แดง กะพริบ | รอฟัง |
| 💬 เหลืองอำพัน หมุน | กำลังถอดเสียง / ตรวจคำเรียก |
| ⚡ เขียว เรืองแสง | กำลังทำตามคำสั่งหรือกำลังตอบ |

- **คลิก:** ปิดไมค์ (ทั้งแบบเต็มและไอคอน)
- **ชี้ค้าง:** ดูข้อความสถานะเต็ม
- **ลากย้าย:** ได้ทั้งสองแบบ จำตำแหน่งแยกกัน
- **กลับตำแหน่งเดิม:** ตั้งค่า › เสียงและไมค์ › **คืนตำแหน่งสถานะไมค์และเพลง**

## 8. ผู้ช่วยส่วนตัว: เมล ปฏิทิน งาน

- **Gmail และ Google Calendar:**
  - ต่อผ่าน MCP ตั้งค่าที่แท็บ **ผู้ช่วย** ต้องใช้ Node.js และ Google OAuth key (ฟรี)
  - **แจ้งเตือน:** เมลสำคัญ, นัดใกล้ถึง, นัดชนกัน, เมลที่ส่งไปแล้วยังไม่มีคนตอบ
  - **เตรียมก่อนประชุม:** สรุปเมลล่าสุดกับคนที่จะประชุมด้วย
- **ผู้ส่ง VIP:** เมลจากคนเหล่านี้นับเป็นเมลสำคัญเสมอ
- **รายการงาน:** สั่งในแชตหรือด้วยเสียง เช่น "เพิ่มงานส่งรายงานพรุ่งนี้" ตัวละครเตือนเมื่อใกล้กำหนด
- **งานตามเวลา:** เช่น `09:00 จันทร์-ศุกร์ สรุปเมลลูกค้า`
- **ปุ่มลัดในแจ้งเตือน:** สรุปให้ / ร่างตอบ / เพิ่มเป็นงาน / เลื่อน 15 นาที
- **บริการอื่นผ่าน MCP:** Outlook, Notion, Slack, Drive ใส่ใน `mcp.json` ตามตัวอย่าง
- **เครื่องมือที่เขียน ส่ง หรือลบข้อมูล:** ถามก่อนทุกครั้ง

## 9. ข่าวและสรุปประจำวัน

ตั้งค่าที่แท็บ **ข่าวและสรุป**
- **หัวข้อข่าว:** ใส่เรื่องที่สนใจ เช่น "ราคาทอง", "AI" ใช้ข่าวจาก Google News และเพิ่ม RSS เองได้
- **ข่าวด่วน:** ใส่คำที่อยากให้เตือนทันทีเมื่อมีข่าว
- **สรุปเช้าและท้ายวัน:** รวมนัด เมลสำคัญ งาน และข่าว ตั้งเวลาได้ อ่านออกเสียงให้ และส่งเข้า Telegram ได้

## 10. Telegram, Vibecode และสั่งคอมจากมือถือ

- **Telegram:**
  - สร้าง bot กับ @BotFather แล้วใส่ token ที่แท็บ Telegram และผูกแชตด้วยรหัส 6 หลัก
  - คุยได้ทั้งข้อความ เสียง รูป และวิดีโอ
  - รับแจ้งเตือนได้ทุกครั้ง หรือเฉพาะตอนไม่อยู่หน้าคอม
- **Vibecode:** สั่ง Claude Code หรือ Codex เขียนโค้ดจากมือถือ
  - คำสั่ง `/create` `/code` `/diff` `/commit` `/pr` `/undo` `/shot`
  - Claude Code ขอสิทธิ์เมื่อไหร่ ปุ่มอนุมัติเด้งใน Telegram
- **สั่งคอม:**
  - `/screen` `/pc` `/lock` `/sleep` `/shutdown` `/restart`
  - ปิดไว้เป็นค่าเริ่มต้น และต้องใส่ PIN ทุกครั้ง
- **LINE:** ส่งแจ้งเตือนเข้า LINE ได้

## 11. เพลงและมินิเพลเยอร์

- **มินิเพลเยอร์:** แสดงเพลงที่กำลังเล่นจาก Spotify, YouTube ในเบราว์เซอร์ หรือเครื่องเล่นใดก็ได้ที่ระบบรู้จัก (ชื่อเพลงภาษาไทยได้) มีปุ่ม ⏮ ⏯ ⏭
- **เต้นตามเพลง:** ตัวละครเต้นระหว่างเพลงเล่น
- **แบบเต็มหรือไอคอนเล็ก ♪:** ตั้งค่า › เสียงและไมค์ › **มินิเพลเยอร์**
  - ไอคอน: คลิกเพื่อเล่นหรือหยุด ชี้ค้างเพื่อดูชื่อเพลง
  - ลากย้ายได้ทั้งสองแบบ และจำตำแหน่งไว้
- **ปิดมินิเพลเยอร์และการเต้น:** ตั้งค่า › พฤติกรรม

## 12. ติดตาม Coding AI

ต่อกับ **Claude Code**, **Codex** และ **Antigravity** ผ่าน hooks (ตั้งในหน้าตั้งค่าครั้งแรก หรือแท็บระบบ)
- **Ticker:** บอกว่า AI กำลังทำอะไร
- **รออนุมัติ:** ตัวละครวาปมาข้างเมาส์และชี้ไปหน้าต่างที่ต้องกด
- **ผลลัพธ์:** เอฟเฟกต์เมื่อคำสั่งล้มเหลว ฉลองพร้อมสรุปภารกิจเมื่อเสร็จ

## 13. คีย์ลัด

| คีย์ | ทำอะไร |
|---|---|
| `Ctrl+Alt+V` | เริ่มพูด / ปิดไมค์ |
| `Ctrl+Alt+M` | ปิดเสียง |
| `Ctrl+Alt+C` | เก็บตัวละครเข้าไบโอชิป / เอาออกมา |
| `Ctrl+Alt+X` | หยุดงานควบคุมเครื่อง |
| `Esc` | หยุดงานที่กำลังทำ |
| `Ctrl` + หมุนลูกกลิ้งบนตัวละคร | เปลี่ยนตัวละคร |

เปลี่ยนคีย์ลัดได้ที่ ตั้งค่า › ระบบ › คีย์ลัด

## 14. แก้ปัญหาที่พบบ่อย

| อาการ | ทำยังไง |
|---|---|
| หน้าตั้งค่าคลิกอะไรไม่ได้ | แก้แล้วใน v0.20 ถ้ายังเจอ ปิดหน้าต่างด้วย Esc แล้วเปิดใหม่ หรือรีสตาร์ทแอป และแจ้งว่าเกิดหลังทำอะไร |
| ไมค์ไม่ทำงาน | ตรวจสิทธิ์ไมค์ของ Windows (Settings › Privacy › Microphone), เลือกไมค์ใหม่ในหน้าไมค์, ถ้าใช้ Local ต้องดาวน์โหลดโมเดลก่อน |
| เรียกชื่อไม่ติด | ดู "เสียงที่ถอดได้ล่าสุด" ในหน้าไมค์ แล้วเพิ่มคำที่ระบบได้ยินจริงเป็นคำเรียกสำรอง |
| ฟังตลอดแล้วสั่งเองมั่ว | ลดความไวไมค์ หรือติ๊ก "ตรวจข้อความก่อนส่ง" หรือเปลี่ยนเป็นโหมดเรียกชื่อ |
| Kokoro อ่านไทยแปลก | ใช้เสียง Xiaoxiao หรือ Xiaobei ถ้าต้องการเสียงไทยชัดที่สุดให้ใช้ Edge |
| ชื่อเพลงไม่ขึ้น | เครื่องเล่นต้องรองรับการควบคุมสื่อของระบบ (Spotify, เบราว์เซอร์ส่วนใหญ่รองรับ), ตรวจว่าเปิดมินิเพลเยอร์ไว้ในแท็บพฤติกรรม |
| ตัวละครหาย | Ctrl+Alt+C หรือคลิกขวาที่ไอคอนถาดระบบ › แสดง |
| อยากเริ่มใหม่ทั้งหมด | ตั้งค่า › ระบบ › ล้างการตั้งค่าทั้งหมด (กดสองครั้งเพื่อยืนยัน) |
| เจอข้อผิดพลาด | ดูไฟล์ `errors.txt` ใน `%APPDATA%\capri-desktop` แล้วแนบมาตอนแจ้งปัญหา |
